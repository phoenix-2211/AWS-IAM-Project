# Stage 7 (Optional Enrichment) Status

Stage 7 (Enrichment: qualitative exploitability labels, MITRE pass-through, and templated remediations) is currently OFF by default. It requires explicit human gate authorization via the token `ENABLE-ENRICHMENT` and team agreement on whether Engine 3 or Engine 4 owns enrichment output. Core Engine 3 outputs (`VerificationResult v0.1`) remain complete, valid, and un-enriched without this stage.
